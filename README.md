# 🌌 WALLSPACE 3D — Cyberpunk Wallpaper Vault

A next-generation **3D Three.js Wallpaper Showcase Gallery** built with the visual styling and cybernetic aesthetics of **X-Stein**. Showcases **380+ Ultra-HD wallpapers** categorized across 13 distinct themes.

![WALLSPACE 3D Preview](assets/css/gallery.css)

---

## ✨ Features

- **🚀 3D WebGL Multi-Mode Showcase**:
  - **3D Cylinder Ring**: Interactive 3D carousel with inertia physics, mouse-wheel zoom, and drag rotation.
  - **3D Sphere Matrix**: Fibonacci geodesic sphere distributing wallpapers across 3D cyberspace.
  - **3D Parallax Wall**: Deep floating cards with dynamic tilt and lighting.
  - **2D Masonry Glass Grid**: Ultra-responsive layout with instant lazy loading.
- **🎨 X-Stein Cyber Aesthetic**:
  - Deep cyber dark palette (`#050a18`) with amber glow accents (`#da7756`), cyan highlights (`#38bdf8`), and high-contrast light mode.
  - Holographic grid dots, neon scanlines, and hover text scramble/decrypt effects.
- **📂 13 Curated Categories (380+ Wallpapers)**:
  - *Animals & Nature*
  - *Anime & Manga*
  - *Cars & Vehicles*
  - *City & Architecture*
  - *Color Schemes (Catppuccin, Gruvbox, Nord, etc.)*
  - *Cyberpunk & Sci-Fi*
  - *Dark & Gothic*
  - *Minimalist & Abstract*
  - *Nature & Landscapes*
  - *OS & Technology*
  - *Pixel Art & Gaming*
  - *Space & Cosmos*
  - *Superheroes & Pop Culture*
- **🔍 Real-Time Search & Sorting**: Instant keyword filter across titles, categories, and filenames.
- **❤️ LocalStorage Favorites**: Bookmark your favorite wallpapers with local persistence.
- **🖼️ Fullscreen HD Lightbox**: High-definition inspection modal with metadata viewer (file size, format, resolution) and direct download.
- **🔊 Cyber Audio Synthesizer**: Interactive WebAudio feedback with sound ON/OFF toggle.
- **⌨️ Keyboard Navigation**:
  - `1`, `2`, `3`, `4`: Switch view modes (Ring, Sphere, Wall, Grid)
  - `/`: Focus search bar
  - `←` / `→`: Navigate lightbox wallpapers
  - `F`: Toggle favorite in lightbox
  - `ESC`: Close lightbox modal

## 🚀 Deploy to GitHub Pages (1-Click)

1. Create a new repository on [GitHub](https://github.com/new).
2. Initialize and push this folder:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - Wallspace 3D Gallery"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git push -u origin main
   ```
3. Go to **Repository Settings** &rarr; **Pages** &rarr; select `main` branch &rarr; Click **Save**.
4. Your gallery will be live at `https://<your-username>.github.io/<your-repo-name>/`!

## 🛠️ Technology Stack

- **Three.js (r128)**: High-performance 3D scene rendering, raycasting, and particle starfield.
- **Vanilla JavaScript (ES6+)**: Zero framework dependencies, instant load times.
- **CSS3 Glassmorphism**: Custom properties, backdrop blur, responsive CSS grid/columns.
- **Google Fonts**: *Space Grotesk*, *Plus Jakarta Sans*, *JetBrains Mono*.
- **FontAwesome 6.5**: Vector iconography.
